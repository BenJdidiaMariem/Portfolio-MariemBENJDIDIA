Modern Data Lakehouse – Dynamics AX 2012

Detandt-Simon International · Sousse

Mise en place d'un pipeline ETL/ELT moderne pour l'intégration et l'analyse décisionnelle des données issues de Microsoft Dynamics AX 2012. L'objectif était de remplacer un processus de reporting manuel et répétitif par une architecture de données automatisée et évolutive.

Missions et réalisations

  • Étude de l'existant et analyse des données de l'ERP Microsoft Dynamics AX 2012.
  • Mise en place de la réplication transactionnelle SQL Server pour extraire les données ERP.
  • Développement de flux d'intégration avec SSIS pour les fichiers Excel.
  • Conception d'une architecture Data Lakehouse basée sur l'architecture Médaillon.
  • Développement de pipelines de traitement et de transformation avec Apache Spark.
  • Orchestration des traitements avec Apache Airflow et conteneurisation avec Docker.
  • Création de tableaux de bord analytiques avec Streamlit.
  • Développement de modèles prédictifs pour anticiper les causes de rupture de stock et recommander des fournisseurs.

Résultats

  • Automatisation du processus d'intégration et de traitement des données.
  • Réduction du temps de traitement, passant d'un délai pouvant atteindre deux jours à environ 17 minutes.
  • Mise à disposition d'indicateurs analytiques et prédictifs pour faciliter la prise de décision.

Environnement technique

Real-Time Financial Data Pipeline

Conception d'un pipeline de données financières en temps réel permettant de collecter, transmettre, traiter et stocker des données de marché provenant de Binance.

Objectifs et fonctionnalités

  • Collecter les données financières à partir de Binance WebSocket.
  • Assurer la transmission des flux de données avec Apache Kafka.
  • Traiter les données en streaming avec Spark Streaming.
  • Orchestrer les traitements avec Apache Airflow.
  • Stocker les données structurées dans PostgreSQL.
  • Conteneuriser les composants avec Docker.

Architecture technique

Binance WebSocket → Apache Kafka → Spark Streaming → PostgreSQL, avec orchestration par Airflow.
